# 통계 탐구실

중학교 '자료의 정리와 해석' 수업용 웹 통계 도구입니다. 통계적 문제해결 4단계(문제 설정 → 자료 수집 → 자료 분석 → 결과 해석)를 따라 탐구합니다.

- 자료 입력: 표 직접 입력(끌어서 복사·붙여넣기), CSV 불러오기, 예시 자료(좋아하는 동물, 1학년 키·몸무게, 가상 자료)
- 대푯값: 평균, 중앙값, 최빈값 (구하는 과정 포함)
- 그래프: 줄기와 잎 그림, 도수분포표, 히스토그램, 도수분포다각형, 상자그림, 산점도
- 상대도수 변환, 두 집단 겹쳐보기/따로보기
- 결과 해석: 앞 단계 내용이 모인 탐구 보고서(캡처용 화면)

입력한 내용은 각 기기의 브라우저에만 저장되며 서버로 전송되지 않습니다.
